When asked to take a screenshot, take it, save or send it, and stop. One line at most.

**Why:** The screenshot is the deliverable. The user is looking at the image; restating what
it shows, tabulating measurements, or re-summarising project state is noise they have to
scroll past to reach the file.

**How to apply:** Capture, write it where asked, name the path. No measurement tables, no
"what it shows", no recap of open items, no restating prior findings. If a capture failed or
came out cropped, say that in one line — a broken deliverable is worth flagging. Volunteer
analysis only when the user asks a question or something is actually wrong.

Applies to any artifact delivery, not only screenshots. Related:
[[feedback_communication_style_explicit_labels_no_pronouns]].

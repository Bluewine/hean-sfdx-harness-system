# Writing Style — Meta-files

Applies when creating or editing:
- `~/.claude/plans/**`
- `~/.claude/rules/**`
- `~/.claude/skills/**`
- `~/.claude/agents/**`
- `**/.claude/rules/**`
- `**/.claude/skills/**`
- `**/.claude/agents/**`

## Language

**Imperative and declarative only.** No hedging, no passive voice, no narrative about how the file came to be.

**One idea per sentence.** Cut every word that adds no meaning.

## Prohibited

- Session history and back-and-forth details
- Marketing adjectives: powerful, seamless, robust, comprehensive, easy
- Filler phrases: "this is a one-time step", "the file itself does not change", "regardless of when this is done"
- Tense that narrates history or expresses future uncertainty

## Structure

- Use labelled bullets or numbered steps for any list of items — not prose paragraphs
- Titles and headers: noun phrases only — no verb phrases, no gerunds
